Audio Reader / 耳読 mimidoku

An audiobook player for the Mudita Kompakt. Choose a folder and that is the library; it keeps your place in each book, and can also read an Audiobookshelf server or a Nextcloud folder.

The library

Point it at a folder of books and tell it once how they are laid out: authors, books, or one book. A folder holding audio is a book, and a folder holding folders is a shelf. Every row says what the scan made of that folder, which is the first thing worth knowing when a book has not turned up.

An author is one shelf however the files spell the name, and the same book twice is listed once. Recent, above the shelves, lists the books you played lately. A swipe down at the top reads an Audiobookshelf server or Nextcloud folder again.

Playing

Big buttons a thumb can find, and the sleep timer, playback speed, chapter list and bookmarks a press away. Each book remembers where you were.

The sleep timer can be set by hand or run on its own between two hours you choose, and a shake keeps it going.

Chapters

Chapters are read from the files' own marks, an mp3's chapter frames or an m4b's chapter list, so thirteen hours still opens as a list rather than one bar to drag.

Servers

Audiobooks can come from a folder on the phone, an Audiobookshelf server you run, or a Nextcloud folder. With Home signed in to Nextcloud, Audio Reader can use that account, so the address and password need not be typed again.

The folder is read through the phone's own folder picker, so it works on a memory card without asking for access to everything on the phone.

With other apps

An m4b opened from a file manager plays as a book of its own, with its chapters, paused at the place you stopped if you opened it before. With Glance installed and Show the book being read in Glance turned on, the book shows on the lock screen; it is off to begin with.

With Shelf installed, a book's page there shows Listen when this library has a recording of it, and opens it here.

Get it

Download the APK and open it, or add the repository to Obtainium to keep it up to date. Audio Reader is written from scratch, and later releases install over it, keeping your settings.
