A file manager for the Mudita Kompakt and for the drives on the servers at home. Other apps open and save through it, and a copy is written whole or not at all.

Places

The start page is a list of places, not the top of a tree: recent files, Downloads, phone storage, the SD card, folders you pinned, and your servers. A swipe down at the top of a folder reads it again. A folder that only another app's picker can reach, Termux's home for one, can be added as a place too.

Delete on the phone moves things to a trash that keeps them seven days, and Restore puts one back, never over something of the same name. A server has no trash here: deleting there cannot be undone from Cabinet, and the button says so before the second tap.

Servers

Any Samba or Windows share, as a guest or with a user name and password, and any Nextcloud or other WebDAV server. Browse, open, copy either way, rename, delete and make folders. A file on a server is fetched to the phone to be opened or shared.

Away from home it reaches whatever the phone can reach, so a server's Tailscale address works with Tailscale on. A Nextcloud is added with an app password; with Home signed in to Nextcloud, Cabinet can use that account too.

Copy and move

A long press starts choosing; a press adds or takes away, and All takes the folder. Then copy, move, delete or share. Pick things up with Copy or Move, go anywhere, and Paste: a phone and a server are the same to it.

A file is written under a temporary name and takes its real name only once every byte has arrived and the size is checked. If a name is already taken, it asks before it starts: keep both, leave those out, or replace. Long copies carry on with the screen off, with a notification that can stop them.

Reading

Text and Markdown files open in a reader that turns by whole lines, with two buttons for smaller and larger text. Markdown is shown as plain reading, and a file of many megabytes opens as quickly as a short one.

PDFs open a page to a screen, fitted whole. A swipe, or a tap near either edge, turns the page, two fingers zoom in on small print, and each PDF opens again at the page it was left at. PDFs from other apps open here too.

Spreadsheets and zips

A CSV, Excel or LibreOffice file opens as a list of its rows with Find at the top: type a few words and only the rows holding all of them stay. Tap a row to see it whole, each heading beside its value. It is read only.

Zip files open like a folder, and Compress makes one. A zip on a server works the same.

Opening files

A file opens in the app that handles it, or asks which with Open with. It installs an APK, and the installer asks once whether to allow installs from here. A contact card opens in Connections to be added, and a GPS track in Topo to be imported.

More, Print on a PDF or a picture sends it through the phone's own print service, which finds most Wi-Fi printers by itself.

Finding things

Search by name below the folder you are in, or everywhere on the phone, and narrow it to documents, pictures, audio, video, archives or apps. Sort by name, date, size or type; numbers sort as numbers, so chapter 2 comes before chapter 10.

Show as a grid lays any folder out three across, with photographs and videos as their own pictures. Info gives size, place and date, and the SHA-256 on request, set out in fours so it can be read against one posted somewhere else.

Nearby

With LocalSend, choose files and press More, Send nearby, then tap a computer or phone on the same Wi-Fi that has LocalSend open. To receive, open Nearby on the start page; you are asked first, and the files land in Downloads.

Away from Wi-Fi, two phones with Cabinet can make a network of their own: start one on one phone, then hold the other against it. A laptop can join it too.

For other apps

Servers also show in Android's own file picker, under Cabinet, so a password vault or an editor can open a file there and save it back. If a save does not reach the server, a copy is kept on the phone, in Download/Unsent saves, and a notification says where.

Cabinet can also answer other apps' Open, Save and Choose-a-folder in its own screens, and can be the phone's file manager: choose it once with Always.

What it leaves out

No small pictures of files on a server, and no Android/data, which Android 12 shuts to every app. A zip is read, never rewritten; a spreadsheet is read, never edited; a PDF is read, not searched or filled in; text is read, never edited.

Get it

Download the APK and open it, or add the repository to Obtainium to keep it up to date. Cabinet installs on any Android 11 or later device, Supernote's tablets among them. Nothing is sent anywhere but to the servers you add and the nearby devices you send to.
