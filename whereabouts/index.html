Whereabouts / 居場所 ibasho

Finds your phone when it is lost: where it is, a ring, a lock. Ask it by text, with no server at all, or through a server you run yourself, which also puts the people who share with you on one map.

Setting up

The first screen asks one question: how should this phone be reached when it is lost? Texts only means a phone you trust texts this one, and it answers with where it is, or rings. Nothing else to set up.

Texts and a server adds a web page with a map and buttons, on a server that you or someone you know runs. Either way the app then asks only for the permissions the commands you use need, one Grant button at a time.

Commands

locate answers with where the phone is. ring rings it at full volume for up to five minutes, through silent mode and Do Not Disturb, and puts the phone's own settings back after. lock locks the screen, can show a message on it, and asks for the phone's password rather than a fingerprint to open it again.

The rest are for the phone you are looking for: turn Bluetooth, location or Do Not Disturb on and off, set the ringer mode, flash the camera light, scan for nearby Bluetooth devices, and stats for the networks around it. help lists them all. The Commands tab shows each one with the permissions it needs.

By text

Text the phone a word and a command, fmd locate for example, and it texts back. No server, no internet and no account: it works wherever the phone can get a text. The word is yours to change.

Another app's notifications can carry commands too, so a message from a chat app can ask where the phone is, and the answer goes back as a reply to that notification. That way always needs the password.

Who may ask

Numbers on the allowed list may send commands as they are. Any other number has to include the password, and is then let in for ten minutes so the password need not be typed again.

Guessing is slow. After five wrong passwords in a row from one sender, that sender's passwords are not checked for an hour, and every one it sends meanwhile starts the hour again; everyone else's still are. After thirty wrong ones in an hour from all senders together, no password sent that way is checked until the hour is over. The phone says when either happens, and the allowed numbers and your server keep working. Passwords show as *** in the app's log.

Locating

Location comes from whatever the phone can offer: GPS, and Android's own fused provider. Indoors, where GPS cannot see the sky, it can also look up nearby cell towers and Wi-Fi networks through BeaconDB and OpenCelliD. Those services learn roughly where the phone is each time they are asked, so a plain locate asks them only once you turn that on in Settings; locate cell asks them because it names them.

What it does not do

It cannot erase the phone. The wipe command is gone, and so is the right to erase. A lost phone can be found, rung or locked; nobody who gets hold of a server login or fakes a text can reset it.

It cannot take a photograph. The camera command is gone, and the camera permission with it. A silent photo is something the person holding the phone cannot know has happened.

Lock from the server is off until you allow it on the phone, since a lock can put any message on the screen.

The server

With a server, the phone uploads where it is every so many minutes, as you set it, and a web page shows it on a map with buttons to ring, lock or locate it now. The place is encrypted on the phone before it leaves, so the server holds it without being able to read it: only the password chosen on the phone opens it, and it cannot be reset. There is no public server and no default; you enter your own.

The Whereabouts server is FMD Server with an ink-on-paper web page, a real dark theme, a gray map and no animation, and the page can be installed as an app. It speaks the same protocol, so Whereabouts works with either. It is one program, built into a Docker image or downloaded as a single file for Linux, and wants a reverse proxy with a certificate in front, because the page decrypts in the browser and browsers only allow that on HTTPS. Set a registration token so strangers cannot make accounts.

Commands reach the phone by push. Whereabouts keeps its own quiet connection to Mozilla's push service for that, so no separate push app is needed; Mozilla learns when your server wakes the phone, not what it asks, which the phone fetches from your server itself. If you already use a push app such as ntfy, pick it instead.

Family

Everyone with an account on the same server is family. On the phone, under Family, you tick who may see where this phone was last, and see the people who share with you, how long ago, and their battery; a row opens their place in a map app. The server's web page shows them on the same map as your own phone.

The server keeps one sealed copy of your last place for each person you ticked, so it can see who shares with whom but not where anyone is. Only the last place is kept, never a trail. A pause switch on the web page stops sharing from a computer if the phone itself is lost. If someone's key changes, their place is hidden until you choose to trust the new one, since that could mean the server is passing someone else off as them.

An iPhone

There is no Whereabouts for the iPhone. Instead an iPhone runs Overland, which posts where it is to a small bridge beside the server, and the bridge seals each point into that phone's account just as the app would, and shares it with the family the same way. One link sets Overland up in a tap. The bridge sees each point before sealing it, which is the price of an iPhone taking part without an app of its own, and it cannot ring or lock the iPhone.

Send where I am

Another app can ask Whereabouts where you are, once. Whereabouts names the app that asked, and on Share takes one fresh fix and hands it back; nothing is kept, and nothing goes anywhere else. Messaging uses this for Send where I am, so Messaging itself needs no location permission. Any app can do the same; the README has the details.

On a Kompakt

DuraSpeed, a service on the Kompakt, closes apps a few minutes after the screen goes dark. Until Whereabouts is let through, it can answer a text but cannot upload on its own or hear the server. Its Setup warnings screen says so, and its Open DuraSpeed button goes to the right place: tap Open, then switch Whereabouts on in the list. On means allowed.

Ringing also needs Display over other apps and Do Not Disturb access, both granted from the app's own buttons.

Get it

Download the APK and open it, or add the repository to Obtainium to keep it up to date. The server comes from its own releases, with checksums beside each file.
